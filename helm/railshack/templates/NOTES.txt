PostgreSQL keeps its data on a persistent volume (PVC data-postgres-0). It survives pod restarts,
upgrades and even `helm uninstall`. To delete the data for good: kubectl delete pvc data-postgres-0 -n {{ .Release.Namespace }}

Watch them come up:
  kubectl get pods -n {{ .Release.Namespace }} -w

  kubectl get ingress railshack -n {{ .Release.Namespace }} -o jsonpath='{.status.loadBalancer.ingress[0].hostname}{"\n"}'
{{- else if eq .Values.access.mode "loadbalancer" }}
Get the public URL from the LoadBalancer Service:
  kubectl get svc frontend -n {{ .Release.Namespace }} -o jsonpath='{.status.loadBalancer.ingress[0].hostname}{.status.loadBalancer.ingress[0].ip}{"\n"}'
{{- end }}
Or port-forward from anywhere:
  kubectl port-forward svc/frontend -n {{ .Release.Namespace }} 8080:8080   →  http://localhost:8080
